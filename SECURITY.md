# Security Policy

## Supported versions

Only the latest released version of ArYS receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Use GitHub's private vulnerability reporting instead:
**Security → Report a vulnerability** on <https://github.com/ronglua111x2/ArYS>.

Include the ArYS version, your Edge version and the steps to reproduce. You can expect a first reply within a week.

## Scope

Things we especially care about:

- any way for a web page or another extension to read, change or remove a user's blocklist;
- any way to remove entries, disable rules, or cancel or shorten a Nuclear lock while it is active;
- anything that makes ArYS send data over the network.
